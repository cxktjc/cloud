# 2026-11-21：行情处理与订单持久化等待分离

运行标识：`20261121-entry-durable-v9`。针对用户实盘分段中的排队 P95 79.717ms、
登记持久化 P95 31.815ms，去掉行情 owner 上每笔登记的同步磁盘等待。
本次仍未达到所有场景收到行情至发送 ≤10ms，不把登记快照变快当作完整发送变快。

## 执行顺序与线程约束

1. 行情 owner 继续串行判断信号、容量、精确 CID、补挂与替换规则，预留物理名额。
2. owner 将完整 intents/state 编码成不可变字符串，提交单独的订单账本写盘线程。
   写盘线程只接触字符串与独立缓存，不读取或修改 owner 的字典。
3. 同时最多一份快照写入、一份等待写入。等待中的完整快照可被更新版本覆盖，
   同组请求共享完成凭据，不无限积压全量文件。
4. 两份必要文件逐份执行原来的临时文件、flush、fsync、原子替换。
   只有成功完成才签发回执。逐文件缓存只在该文件成功后更新；第二份失败不能跳过重试。
5. 网络 worker 先等待该次保存的回执，并核对回执中的“币对/CID 精确意图＋物理名额”。
   最新合并快照若已撤销该身份，旧请求明确拒绝，不能借用别的订单的回执。
6. 取得回执后，入场仍检查当前信号/名额/时效及最新 tick/bid0，再调用发送。
   写盘失败发生在真正调用网络之前，按已知未发送处理；发送后丢 ACK 继续保留 UNKNOWN 身份。
7. 停止时先撤销新网络准入、等在途 worker 退出并应用结果，再保存最终账本、等待写盘线程退出。
   只有这样才释放进程锁。显式 `ledger.flush()` 仍可同步等待，离线工具保留原同步语义。

两份 JSON 文件及其顶层结构不变，启动恢复和既有人工同步工具沿用原格式。
实时且开启非阻塞 I/O 的 trade 使用后台订单账本；paper/dry-run/同步模式保留同步路径。
改变的是磁盘等待所在的线程，发送前的持久化边界仍然存在。

另外，新任务入队只唤醒一个空闲网络 worker，避免每笔新单同时唤醒全部 19 个。
实时 trade 的 Python GIL 切换间隔默认 1ms，退出时恢复原值。
可通过 `V9711_LIVE_GIL_SWITCH_SECONDS` 设置 0.0005～0.005 秒；默认无需额外配置。
没有增加 I/O worker 上限，没有合并丢掉价格变化，也没有放宽 0.5 秒行情保护。
普通撤单仍按前笔返回后间隔 1.5 秒执行。

## 指标口径

“登记”现在表示 owner 完成精确名额登记并提交不可变快照，不再冒充磁盘完成。
面板分开显示：排队、选单、登记快照、worker 调度、等待落盘、落盘后发送。
未成交详情增加落盘完成时间；总发送延迟继续从原接收时刻计时，完整包含磁盘等待。
“等待落盘”是 worker 等到正向回执的时间，包含该 worker 的唤醒成本；
后台账本行另外显示写盘耗时、待写数、合并数、失败次数与当前错误。
每笔完整链路不重复展示包含落盘等待的旧“线程→发送”总段；各段 P95 也不可直接相加。

## 同条件对照

基线为 cloud 提交 `eb69bf5` 的只读解包副本。两版都用本次相同的离线压力脚本：
800 币、2 个逻辑核心亲和性、19 个 worker、约 54KB 填充加活动状态、真实临时文件 fsync、
真实 broker 线程/HMAC/JSON、假 socket 发送，无 Binance 访问或真实下单。
账户健康/订单证据和终端输出使用替身；不含真实 TLS、云磁盘、虚拟 CPU 配额及公网网络。

本次将服务器生成的背景行情 JSON 预先构造，计时内只做客户端解码。
这修正了此前脚本还在客户端计时内支付服务器逐帧编码成本的测试范围。

## 回归与复跑

完整回归 511 项通过，13.971 秒。新增覆盖：

- 磁盘卡住时 owner 继续收行情并预留 8 单，回执前实际发送为零。
- 新快照覆盖等待快照时，所有仍有效的精确身份与递增序号可恢复。
- 编码快照提交后改变内存，后台文件不混入未提交修改。
- 两文件第二份失败不签发回执；重试能补全缺失状态。
- 合并快照不含旧物理名额时，旧网络请求不能发送。
- 写盘失败明确未发送；反弹和信号撤回仍在落盘后阻止发送。
- 平仓身份回执要求 close 意图和实际持仓的 close 名额同时存在。
- 真正发送后丢 ACK 保留 UNKNOWN、精确身份及名额，退出旧 writer 后能恢复。
- 退出保存最新状态、可重复关闭、恢复原线程切换间隔。
- 磁盘等待仍完整出现在总发送延迟及新分段统计中。

原有名额、补挂、替换、撤单节奏、时间平仓、unknown 不重发及双行情准入回归继续通过。
